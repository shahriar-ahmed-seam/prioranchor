# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability within PriorAnchor, please report it via responsible disclosure rather than filing a public issue.

Send vulnerability details including:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediations if available

Email security reports to: `security@prioranchor.dev`

All reports will be acknowledged within 48 hours, and security patches will be published with dedicated advisory notices.
